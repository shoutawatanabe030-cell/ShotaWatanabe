# Coherence Symphony ミュージックビデオ

テーマ: **波動による全宇宙の調和**
宇宙・銀河・惑星・あまたの星々が、地球を中心に周波数（波動）によってひとつに調和していくイメージ。

- 形式: 横長 1920×1080 / 30fps / H.264 + AAC（元音源をそのまま使用）
- 長さ: 4分27秒（曲の長さと同じ）
- 歌詞テロップ: 画面下部に表示。日本語の行の下に英訳を小さく表示（英語の行は訳なし）。サビは2行ずつ表示し、いま歌っている行を明るくする
- 動画ファイル本体はサイズが大きいため、このリポジトリには入れていない

## v4（2026-11-22 最新版）: 静止画のカットをすべて動かす

依頼「静止画が多いので、全てアニメーションで動かして」を受けた版。ソースは `src_v4/`（人物画像は `src_v3/photos/` を共用）。

- 要所のカットは Canva の AI 動画（人が実際に動く映像）にする予定だったが、Canva の今月の AI 利用上限が足りず作成できなかった（上限のリセットは 2026-12-07 9:00）。リセット後に要所だけ差し替えられる
- 代わりに、人物の写真カット31カットすべてを加工で動かした（`src_v4/photo_anim.py`）
  - ピントの合った部分（人物）と画面の上下から奥行きを推定し、カメラの動きで手前と奥がずれる立体的な動き
  - 人物の呼吸・ゆれ、空や雲の流れ、水面のゆらぎ、光の帯の流れ、拍に合わせた光の脈動
  - 雨（街・窓辺）、漂うボケた光、マグカップの湯気、落ち葉、海辺のもや、光のちり
- カットごとの動きの設定は `src_v4/mv4.py` の `ANIM`

## 作り方（再生成する場合）

`src/` のスクリプトで作成。すべてプログラムで描画している（素材写真は地球の画像のみ）。

1. `transcribe.py` … Whisper（small）で歌声の単語タイミングを取得
2. `lyrics.py` … 上の結果をもとに作った歌詞の表示タイミング表（秒）と英訳。テロップのずれや訳を直すときはここを編集する
3. `analyze.py` … 音源から拍・低音・スペクトルを抽出（映像を音に合わせるため）
4. `mv.py` … 映像を描画して音声と合成

```bash
pip install numpy opencv-python-headless pillow librosa faster-whisper soundfile
python3 analyze.py song22k.wav assets/audio_feat.npz
python3 mv.py still 90 205             # 指定秒の静止画を確認
MV_AUDIO=元音源.m4a python3 mv.py render Coherence_Symphony_MV.mp4
```

`assets/` に必要なもの（リポジトリには未収録）:

- `bmng.jpg` … NASA Blue Marble の地球画像（パブリックドメイン。PyPI の `basemap-data` パッケージに同梱）
- `fonts/ShipporiMincho-500.ttf`, `ShipporiMincho-700.ttf`, `Cinzel-400.ttf`, `Cinzel-600.ttf`, `CormorantGaramond-Italic-600.ttf`（英訳用） … Google Fonts（SIL Open Font License）
- `audio_feat.npz` … `analyze.py` の出力
